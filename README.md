# Simple Launcher — Android 15 Tablet Project

This repository is pre-configured to build a debug-signed, installable **APK** on GitHub Actions!

## How to Build the APK on GitHub in 3 Easy Steps:

1. Create a new repository on GitHub (e.g. `simple-tablet-launcher`).
2. Unzip this downloaded archive and commit all files to the root of your GitHub repository.
3. Click the **Actions** tab on GitHub:
   - The "Build Android APK" workflow will run automatically.
   - Once completed (takes ~1.5 - 2 minutes), click on the run.
   - Scroll down to **Artifacts** and download `simple-launcher-debug-apk.zip`!
   - Unzip the artifact to get `app-debug.apk`.

## Installing on your Android Tablet:
1. Transfer `app-debug.apk` to your tablet via USB, Google Drive, or email.
2. Tap the APK file to install (allow "Install unknown apps" if prompted).
3. Press the tablet Home button and select **Simple Launcher** -> **Always**.
